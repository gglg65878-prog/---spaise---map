# АРКА

Кликабельный прототип студенческого архитектурного сообщества. Три листа одного чертежа: карта, категория и фокус.

## Запуск

Откройте `index.html` в браузере. Зависимости и сборка не нужны. Для локального HTTP-предпросмотра можно запустить `python -m http.server 8000` из корня проекта и открыть `http://localhost:8000/`.

## Что где менять

| Файл | Содержимое |
| --- | --- |
| `index.html` | Общая оболочка сайта и переключатель движения |
| `content.js` | Пять разделов, карточки и тексты для экрана фокуса |
| `styles.css` | Палитра, типографика, мобильная раскладка и анимация штриха |
| `app.js` | Маршруты, переходы, поле крестиков и расчёт SVG-рамок |
| `assets/` | Эскиз знака и аксонометрия портала |

Содержание разделов сверено с [исходным сайтом](https://arka-studio-community.amirov-b26.chatgpt.site/). Карточки исследований и событий с пометкой «Пример» иллюстрируют механику. Форма идеи скачивает текстовый черновик на устройство.

## Механика чертежа

- На карте три горизонтальные и три вертикальные оси. Пять пересечений открывают разделы, а четыре служат опорными метками. На компьютере зона наведения каждого узла составляет 88 × 88 px при графическом знаке 40 × 40 px. Знак подпрыгивает сразу, условное обозначение и название появляются после секунды наведения. При фокусе с клавиатуры обозначение видно сразу. На сенсорном экране названия подписаны под крестами.
- На листах категории и фокуса Canvas рисует фоновые крестики одним контуром. В покое кадры не запрашиваются. При переходе точки на 420 мс смещаются от центра выбранного узла.
- При выборе узла CSS-трансформации через Web Animations API приближают сцену к точке выбора. Уход и появление экранов занимают около 435 мс. Внешняя библиотека для этого перехода не нужна.
- На листе категории `drawFrame()` считывает центры опор через `getBoundingClientRect()`. Общие узлы и стороны объединяются, длинные стороны в Т-стыках делятся на отрезки. Луч крестика равен 6 CSS-пикселям и ещё 6 остаются пустыми до начала линии.
- Каждый штрих SVG получает `pathLength="1"`. При смене листа прежние штрихи исчезают, новые рисуются изменением `stroke-dashoffset` от 1 до 0. При изменении размеров окна координаты пересчитываются.
- Тот же алгоритм строит рамку на листе фокуса. Можно вернуться по навигационной цепочке, клавишей Esc или кнопкой браузера. По умолчанию учитывается системная настройка уменьшенного движения.
